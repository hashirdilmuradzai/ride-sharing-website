# Ride Sharing Website

A responsive ride-sharing landing page built with HTML and CSS. This project is inspired by Tere, a ride-sharing platform, and focuses on presenting its services, features, and benefits through a modern website design.

## 🚀 Features

- Modern navigation menu
- Responsive landing page layout
- Hero section with app download buttons
- Mobile number signup form
- How It Works section
- Ride-sharing features and benefits
- App download section
- Footer with contact information
- Mobile navigation menu

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Concepts Practiced

- Semantic HTML
- CSS Flexbox
- Responsive Web Design
- CSS Media Queries
- CSS Positioning
- CSS Styling and Layout
- HTML Forms
- Navigation Menus

## 🎯 Purpose

The purpose of this project is to practice frontend development, improve responsive design skills, and build a modern landing page for a ride-sharing platform.
